# Digital Business Card

A clean, modern static business card component built with React and Tailwind CSS. The interface displays profile details, action buttons, personal background, and dynamic social media links, complete with automatic light/dark theme adaptation based on system preferences.

- **React** — Component-based UI Architecture

- **Vite** — Modern frontend build tooling

### 🧠 What I Learned & Practiced

While I already have experience working with React and Tailwind CSS, building this card allowed me to refine my workflow around component design and utility styling:

- **Modular Component Architecture:** Divided the card layout into dedicated, self-contained sub-components (such as header, main content, and footer) to keep the codebase structured and readable.
- **Dynamic System-Based Theme Adapting:** Leveraged Tailwind's native dark mode utilities (`dark:`) to allow the card color scheme to seamlessly adjust according to the user's system preferences.
- **Dynamic Data Rendering with `.map()`:** Refactored repetitive element lists—specifically the social media links in the footer section—by mapping over data arrays to render dynamic components cleanly and maintainably.
- **Utility-First Styling Precision:** Focused on pixel-perfect alignment, spacing, and typography using standard Tailwind utilities without writing custom CSS overrides.
